核心架构：两条互补的编织通道

① render="ribbon"（默认，区域切分）

丝带是一个多边形区域：偏移线求交 → miter 接头 → 配对 → 挖区间 → 显式构造孔洞（_set_holes）。

几何在 interlacing.py有孔洞 / 支持 3DA/B 底线适用可半透明

代价：难点全在"一次交叉的四个角点"—— 拐点/切触退化时需要表示层改造（未完成）。

② render="stroke"（新，中心线 + 描边）

丝带 = 中心线 + stroke_width：事件取中心线交叉弧长，断口 = offset / |sinθ|，孔洞不需要构造（没被盖住的就是背景）。

几何在 stroke.py无孔洞 / 无 3D必须不透明A/B 不适用（并存通道）

代价：浅角交叉残留 offset²·cotθ 三角、交替无解时退化为整条描边。

两条通道的公共输入通道是 mobject_paths()（按三次贝塞尔采样，CURVE_SAMPLES = 8）；纯直线/多边形输入几何逐字节不变。

技术栈与工程约定

Python ≥3.10（本机 3.11）manim 0.22（0.3.0）numpy / scipy / networkxuv 管理依赖pytest + ruffGitHub Actions

  • 核心（代码与测试）不得 import 玫瑰线；rosette 为可拆分的可选模块（PEP 562 惰性转发）。
  • 任何容差必须尺度无关（比 sinθ，不比叉积绝对量）。
  • 输出多边形统一逆时针、首尾点重复；空输入退化为空结果；非法参数抛 ValueError；几何不可实现显式报错，绝不产出 inf/nan。
  • 不可编织时诚实降级（整条丝带 + 汇总 UserWarning），宁可不变好，不可静默画错。
